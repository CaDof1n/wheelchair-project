## 五、一致性校验

V1.0 出稿后按下列方式校验，结论记录于此：

- **题注完整性**：文档共 40 张表，题注 40 条，一一对应，无无题注表。
- **引用可解析**：正文中所有 `表 N-M` 形式的引用均能在题注集合中找到对应项。
- **注册表交叉比对**：`interface_registry.yaml` 的 topic 名（33 条）、
  service 与 action 名（7 条）、TF frame 名与 表 4-3 / 表 4-4 / 表 5-1 完全一致。
  frame 一项的差异为注册表把六轴关节链压缩登记为 `arm_link_1..arm_link_6`，属有意为之。
- **串口示例帧复算**：第 6.7 节的示例帧 CRC 由生成脚本按帧内容重新计算，
  结果 `0x8122`，与注册表 `serial.example_frame` 一致。
