# 归档说明 · archive/

本目录保存 **IW-IF-STD-001 在正式发布前** 的历次内部草案。
这些文件**不再对外引用**，任何评审、验收和联调均以仓库当前版本为准。

## 为什么归档

这三份文件都是**在未与其他五个大组逐条对表之前**编写的内部雏形：

- 五组当时尚未给出实际选型（ROS 2 发行版、SLAM 框架、上位机平台、传感器型号与频率、
  串口链路拓扑、机械臂控制器名等均未确定）；
- 其中若干定义与五组后来的方案汇报**直接冲突**（详见
  `../各组汇报接口对齐差异清单.md` 的 D 类条目）；
- 部分内容（如 `/tf` 的 QoS 档、超声波频率、心跳超时、故障位表）经核对**存在错误或缺口**。

把草案继续与正式版并列存放，会让「哪一份才算数」在跨组联调时产生歧义。
因此旧稿统一降级归档，版本号**重新起算**：新标准为 **V1.0**，与旧稿的 V1.0 / V1.1
**无继承关系**。

## 仍被引用的内容

草案中**经核对仍然成立**的内容已全部并入新版
`../第一版全局软硬件接口标准_V1.0.docx`，包括：

- 串口帧格式（SOF、VERSION、MSG_ID、FLAGS、SEQ、LENGTH、PAYLOAD、CRC-16/MODBUS）；
- 表 6-4 至表 6-7、表 6-12 已有的载荷与故障位定义；
- 附录 A 的 6 个 `.msg` 与 2 个 `.action`（本版仅做常量前置的语法修正）；
- 第 3 章命名规则、第 7 章网络与时间同步、第 8 章 Git 与变更流程。

新旧表号对应关系见 `../表号映射表.md`。

## 维护约定

**禁止**在本目录内继续编辑草案文件，也**禁止**从未归档的旧稿复制接口定义到新分支。
发现草案中有价值的遗漏内容时，按第 8.4 节的接口变更流程提交 ICR，
由接口所有者评审后并入当前版本。
